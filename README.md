# Mohamed Hamed Sallam Portfolio

Static portfolio website for Mohamed Hamed Sallam, Software Engineer.

## Production

This site is plain HTML, CSS, and JavaScript and can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting provider.

The production entry point is `index.html`. No build step or server runtime is required.

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server.

## Contact form

The contact form opens the visitor's default email client with a prefilled message. A server-side form provider can be connected later if inbox delivery without an email client is required.

## Deployment notes

- Keep the repository private unless the site is intended to be published with GitHub Pages.
- Configure the final production domain in the hosting provider before adding a canonical URL or sitemap.
- RAW camera files, backups, duplicate source folders, and private working notes are excluded through `.gitignore`.
